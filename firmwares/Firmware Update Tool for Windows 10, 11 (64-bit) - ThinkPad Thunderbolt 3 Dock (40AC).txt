WHAT THIS PACKAGE DOES

  This package updates the firmware (ThinkPad TBT3 Dock) to update the
  following chip of dock.

  Chip                     	 Chip name in the Dock
  ------------------------------------------------------------------------------
  Intel TBT3                     JHL6540
  Synaptics DP HUB               VMM3320
  Fresco PCIE USB HUB            F1100EX
  Conexant Audio                 CX20985B
  SiliconLab MCU                 EFM8UB20F64G

  Refer to marketing materials to find out what computer models support which dock.

  If this package has been installed, this package will fix problems, add new functions, or expand functions as noted below.

  This program is language independent and can be used with any language system.

DETERMINING WHICH VERSION IS INSTALLED

In File Manager

  1. Locate the file that was downloaded and double-click "Run_Check_Version.bat".
  2. Batch file will return below return code:
     0 : Ready to update.
     1 : No need to update or dock was not ready/connected.

INSTALLATION INSTRUCTIONS

Notes:
- If your dock runs satisfactorily now, it may not be necessary to update
  the software. To determine if you should update the software, refer to the
  Version Information section.


Manual Install

  This section assumes to use Internet Explorer and Windows Explorer.

  Download File
  -------------
  1. Click once on the underlined file name(ar_tbtdockfw10.exe). Once this is done, some pop-up windows will appear.
  2. Follow the instructions on the screen.
  3. Choose the folder you would like to download the file to and click Save.
     A different window will appear and the download will begin and complete.
     Once the download has completed, there may or may not be a message stating that the download completed successfully.
  4. Make sure to be logged on with an administrator account.
  5. Locate the folder where the file was downloaded.

  Update Firmware
  ---------------
  Method 1:
  (Install option)
  1. For UI mode: Double-click ar_tbtdockfw10.exe .
  2. Follow the instructions on the screen, choose "Install" and then press "Update" button to complete FW update.

  Method 2:
  (Extract only option)
  1. For UI mode: Double-click ar_tbtdockfw10.exe .
  2. Follow the instructions on the screen, choose "Extract only".
  3. In the "Select Destination Location" window, click Extract. If you would like to select a different folder, click Browse.
  4. In the Ready to Install window, click Install. All the necessary files will
     be extracted to the folder you selected. (Default: C:\DRIVERS\Tbt3ArDockFwUpdateTool)
  5. Locate to the extracted folder and double-click Fwupdate.exe and then press "Update" button to complete FW update.
  6. For Silent Mode without prompt and force update: At the command line mode and execute [File extracted folder\]Fwupdate.exe /u /s /f

  Method 3:
  Unattended Install

  This is for system administrators' use only.

  1. Refer to the Manual Install section, and download and extract the 7z file.

  2. For Silent Mode without prompt and force update: At the command line, execute ar_tbtdockfw10.exe /u /s /f /VERYSILENT .
     Example: [Path where the 7z file was extracted\]ar_tbtdockfw10.exe /u /s /f /VERYSILENT
